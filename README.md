# Smart Attendance Tracker

A Flask-based web application designed to help students and teachers manage class timetables, mark daily attendance, track subject-wise attendance percentages, and export monthly attendance reports.

---

## 🚀 Features

- Monthly calendar view of class timetable
- Predefined weekly timetable with subjects and faculty
- Mark attendance as Present/Absent
- Mark special holidays
- Automatic attendance percentage calculation
- Subject-wise and overall summary
- Export monthly attendance report as CSV
- JSON-based local data storage

---

## 🛠️ Tech Stack

- Python (Flask)
- HTML, CSS, JavaScript (Frontend)
- JSON (Data storage)
- Calendar & DateTime modules
